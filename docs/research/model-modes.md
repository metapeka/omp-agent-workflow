# Model modes and cache economics for handoff/preflight

Статус: `[design]`. Не контракт, не поведение плагина. Экономика 0.6
отложена до API cache-monitor; этот документ — вход в решение владельца.

Дата: 2026-11-24. Источники: `~/.omp/agent/models.db` (цены cline-pass,
проект gridsnape) и `~/.omp/agent/sessions` этой машины (замеры handoff).

## TL;DR

- Граница handoff — единственная санкционированная точка смены модели;
  плагин сам модель не меняет и не будет (read-only к деньгам).
- Цена границы зависит не от размера контекста, а от кэша **целевой**
  модели: тёплая голова — 0.01–0.3 хода, холодная — 0.8–1.2 хода.
- Мышление `auto` на flash (+$0.006/ход на 100k) дороже, чем перейти на pro
  без мышления (+$0.0039/ход): plan на pro — дешевле «thinking на flash».
- Замер 20 реальных handoff: payload 81–21 363 символа, медиана 5 271;
  новых токенов первого запроса 0.07–3.85k, медиана 1.9k. Лимит 32k
  символов почти не достигается.
- Открытый риск: TTL кэша у целевой модели не проверен ни в одном из двух
  проектов. В планы закладывать как неизвестное, не как факт.

## Замер handoff-payload (эта машина, 20 сессий)

Метод: `~/.omp/agent/sessions/**/*.jsonl`, событие `custom_message` с
`customType: "handoff"` (это ровно `continuePrompt` + содержимое state),
и первый `message.role=assistant` с `usage`.

| Метрика | min | медиана | среднее | max |
|---|---|---|---|---|
| payload, символов | 81 | 5 271 | 7 858 | 21 363 |
| первый запрос, всего токенов | 12 236 | — | — | 14 511 |
| из них cacheRead | 9 856 | — | — | 14 080 |
| новых токенов (input) | 73 | 1 886 | — | 3 850 |

- Стабильная голова (system + tools) ≈ 12–14k токенов и часто попадает в
  провайдерский кэш уже на первом ходе новой сессии (cacheRead 9.8–14.1k).
- Payload типично 3–8k символов ≈ 1–3k токенов [INFERENCE: пересчёт по
  ~2.5 символа/токен для русского текста; измеренные новые input-токены
  согласуются].
- Живые `HANDOFF.md`: 22 037 и 29 399 символов — верхний край, но ниже
  лимита 32k.
- cacheRead кратны 128 токенам (640, 2 560, 10 496, 14 080): провайдер
  кэширует блоками; точный размер блока не проверялся.

Прежняя оценка «10–15k токенов payload» была производной от лимита 32k
символов, а не от замеров. Правильная цифра — медиана ~2k.

## Цена границы handoff

| Случай | Токены | Стоимость | В ходах на 100k |
|---|---|---|---|
| та же модель, голова тёплая | 0.07–3.85k новых | flash $0.00002–0.0012; pro $0.00004–0.0020 | 0.01–0.3 |
| переход на pro, холодный кэш | 12–14.5k input | $0.0063–0.0076 | 0.8–1.0 (pro) |
| переход на flash, холодный кэш | 12–14.5k input | $0.0036–0.0044 | 1.0–1.2 (flash) |
| тёплая голова, cacheRead | 10–14k | flash $0.00006–0.00009; pro $0.0004–0.0006 | — |

Следствие: «второй промах» возникает только при возврате в режим/модель,
которую покинули; схема «plan на pro → handoff → flash без возвратов»
платит ровно одну холодную границу.

## Режим v1 (предложение gridsnape, сведено)

| Параметр | routine | plan-heavy | review |
|---|---|---|---|
| Сессия | flash | pro — первая сессия волны | flash |
| Thinking | off (auto = +$0.006/ход) | auto; high/xhigh только при необходимости | auto |
| Advisor | off | off | pro, только на план/дифф: $0.0019–0.0052 за артефакт [оценка gridsnape] |
| Смена модели | — | handoff 55% → flash | — |
| Бюджет | $0.072/волна | $0.150, из них $0.0076 граница | +$0.002–0.005 на артефакт |
| Порог handoff | 55% (yoda) | 55%, plan-фаза до handoff | 55% |
| prewalk | off | off | off |

Ограничения реализации: режимы плагина (`manual`/`assisted`/`yoda`/
`yoda-supervised`) задают только пороги и supervisor — ролей моделей в
контракте 0.3 нет; v1 требует отдельного решения.

## Что это значит для контракта плагина

| Пункт | Предложение | Статус |
|---|---|---|
| `modelRoles.plan` / `slow` | `cline-pass/deepseek-v4-pro`; `default`/`smol` — flash | `[future]`, Settings-ключ, не env |
| Advisory в state | строка `next-session: model=… thinking=… role=…`; preflight только показывает | `[design]` |
| Счётчик переходов модели | advisory-поле в `STATE.json`, не блокер | `[future]`, изменение контракта |
| Оценка границы в preflight | «холодная цель $0.006–0.008, тёплая $0.0001–0.001» | `[design]`, только если есть цены из cache-monitor |
| TTL кэша | неизвестен; в документе — риск, не факт | открытый риск |

Плагин не переключает модель: `ctx.newSession()` доступен только в command
context, event-handler не может ни начать сессию, ни сменить модель;
preflight read-only по контракту 0.3.

## Синтаксис advisory-строки (предложение)

Одна строка в начале state-файла (`HANDOFF.md`), чтобы её читал следующий
агент, а не человек:

```
next-session: model=cline-pass/deepseek-v4-pro thinking=auto role=plan
```

Правила разбора:

- строка начинается с `next-session:` в начале строки; ровно одна на файл;
- дальше пары `key=value` через пробел; значения без пробелов;
- известные ключи: `model` (`provider/model`), `thinking`
  (`auto|off|low|medium|high|xhigh`), `role` (`routine|plan|review`),
  `reason` (slug без пробелов);
- неизвестные ключи игнорируются читателем и сохраняются при правке;
- отсутствие строки = рекомендации нет;
- значения не влияют на пороги, marker и supervisor: это только подсказка
  следующей сессии.
